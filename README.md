# GreenDen

A responsive plant and gardening website built as a frontend web development project.

## Overview

GreenDen is a clean, responsive website for exploring plant and gardening products. The project focuses on responsive layouts, navigation, product presentation, and interactive frontend elements.

## Features

- Responsive navigation
- Home, products, and contact pages
- Product-focused UI
- Mobile-friendly layout
- Interactive navigation using JavaScript
- Responsive styling with Tailwind CSS

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Pages

- Home
- Products
- Contact

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/Sabi0603/greenden.git
cd greenden
```

The project is a static frontend application, so no backend setup is required.
